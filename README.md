# RecommendMovieApp

Приложение для рекомендаций фильмов на базе данных The Movie Database (TMDB).

## Требования

- macOS
- Xcode (рекомендуется последняя стабильная версия)
- Аккаунт и API key в TMDB

## Быстрый старт

1. Откройте проект в Xcode.
2. Настройте TMDB API key (см. ниже).
3. Соберите и запустите приложение на симуляторе или устройстве.

## Настройка TMDB API key (без коммита секретов)

Ниже описан вариант, при котором ключ хранится локально в `.xcconfig` и не попадает в репозиторий.

### 1) Создайте `Secrets.xcconfig`

В корне проекта создайте файл:

- `Configs/Secrets.xcconfig` (если папки `Configs` нет — создайте её)

Добавьте в `Configs/Secrets.xcconfig` строку:

```
TMDB_API_KEY = ваш_ключ_здесь
```

### 2) Подключите конфиг в Xcode

- Откройте настройки проекта → вкладка **Info**
- В секции **Configurations** для **Debug** и **Release** укажите `Configs/Secrets.xcconfig`

### 3) Добавьте ключ в `Info.plist`

Откройте `Info.plist` и добавьте пару ключ-значение (перед закрывающим `</dict>`):

```
<key>TMDB_API_KEY</key>
<string>$(TMDB_API_KEY)</string>
```

После этого приложение сможет читать значение `TMDB_API_KEY` из `Info.plist` (а подставляться оно будет из `Secrets.xcconfig`).

## Структура (в общих чертах)

- `Configs/` — конфиги сборки (в т.ч. локальные секреты в `Secrets.xcconfig`)
- Остальные папки/модули проекта — исходный код приложения (Swift)

## Частые проблемы

- **Ключ не подставляется**: проверьте, что в `Secrets.xcconfig` используется именно `TMDB_API_KEY`, и что файл подключён для нужной конфигурации (Debug/Release).
- **Сборка не видит файл `Secrets.xcconfig`**: убедитесь, что `Configs/Secrets.xcconfig` добавлен в проект (виден в Project Navigator), и путь указан без опечаток.

## Безопасность

Не коммитьте `Configs/Secrets.xcconfig` в git. Если файл уже попал в историю — лучше отозвать ключ в TMDB и выпустить новый.
